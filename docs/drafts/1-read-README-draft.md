# How to read this project

This folder holds everything you need to understand what the project found and how far to trust it.
Read it in the order below.

## Reading order

| Step | File | Time | What you get |
|---|---|---|---|
| 1 | [`purpose.md`](purpose.md) | 3 min | What the project is for, and what it deliberately does not do |
| 2 | [`glossary.md`](glossary.md) | 3 min | Plain definitions: alert, record, wave, match, oblast, median |
| 3 | [`summary.md`](summary.md) | 10 min | Everything done, the key numbers, and what was checked |
| 4 | Chapters 1 to 9 (below) | 5 to 10 min each | One question per chapter, with its limits |
| 5 | [`safety.md`](safety.md) | 3 min | The rules the project keeps: what it will never claim |
| 6 | Chapter 10 (below) | when needed | How to rerun the numbers yourself |

## How to read a chapter

1. Read the **short version** first. It gives the answer in a few lines.
2. Look at the **figures**. Each has a caption that says what it counts.
3. Read **"What this chapter cannot tell you"**. It is the most important part.
4. Read the **method** only if you want to check a number or rerun it.

## Two rules that apply everywhere

- Every number has a limit next to it. If a limit is missing, that is a mistake: report it.
- Missing periods are shown as missing. They are never filled with zeros.
