# Kaggle "Massive Missile Attacks on Ukraine": data profile (2026-10-12)

Source: Petro Ivaniuk, https://www.kaggle.com/datasets/piterfm/massive-missile-attacks-on-ukraine
Licence (dataset page): CC BY-NC-SA 4.0. Downloaded by the owner's signed-in session on 2026-10-12.
Files: `data/raw/kaggle_missile/` (gitignored, not in the repo). SHA-256 in
`data/raw/kaggle_missile/SHA256SUMS.txt`.

## missile_attacks_daily.csv

- 4,224 rows, 22 columns. No exact duplicate rows.
- Date range (`time_start`): 2022-09-28 to 2026-10-09 18:00.
- Two timestamp formats in one column: date only (2,449 rows) and date+time (1,775 rows). Parse
  with per-element inference. A plain `pd.to_datetime` call silently coerces 2,450 rows to NaT.
- Rows per year: 2022: 103, 2023: 528, 2024: 1,349, 2025: 1,266, 2026: 978. 2022 is sparse.
- **Coverage gaps: 228 of 1,473 calendar days (2022-09-28 to 2026-10-09) have no record.**
  A missing day is an absence of data, not a zero-strike day. Do not fill it with 0.
- Key columns: `launched`, `destroyed`, `not_reach_goal`, `num_hit_location`, `is_shahed`,
  `target_main`, `affected region`, `source`.
- Missing: `launched` 3 rows, `destroyed` 6 rows.

## Provenance (blocker)

Every row has a `source` value. Counts of the top prefixes:
- `kpszsu` (Ukrainian Air Force Telegram channel): 2,411
- `PvKPivden`: 1,583
- `pvkshid`: 174
- `PvkZahid`: 18
- `GeneralStaff.ua`: 13

**The file is an aggregation of Telegram channel posts.** The Telegram API terms (clause 1.5, see
`docs/enterprise/candidates_review.md`) prohibit "using, accessing or aggregating data obtained
from the Telegram platform," including for machine learning models. This is the same
restriction that blocked @kpszsu as a direct source. Using a third party's Telegram-derived
dataset is a secondary use, and it does not clear the restriction on its own. Owner decision
required before any modelling.
